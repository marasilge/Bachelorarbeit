# Formalizing the Homotopy Extension Property in Lean

This repository contains my bachelor thesis on formalizing the **Homotopy Extension Property (HEP)** in the Lean theorem prover, along with the accompanying Lean code.

Both the thesis and the code in this repository are **not final versions** and are actively being worked on. The code and thesis text will continue to change until submission.
